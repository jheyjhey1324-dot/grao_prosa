# ☕ Cafeteria Grão e Prosa

O Grão e Prosa é um projeto acadêmico que consiste na criação e no desenvolvimento de um site para uma cafeteria fictícia, com uma proposta visual acolhedora e uma identidade própria.

O projeto foi desenvolvido com o objetivo de aplicar conhecimentos de desenvolvimento web em Front-End, organização de páginas e construção de interfaces.

## 📖 Sobre o projeto

O site ele é composto principalmente por:
HTML: estrutura semântica header, nav, main, section, article, form, fieldset.
CSS: um arquivo global e um por página, com variáveis de cor, Flexbox, Grid e media queries.
JavaScript: paginação do cardápio, avaliação da equipe, leitura dos dados enviados por GET, menu para celular e máscara de telefone.

Além disso, como um projeto busca se desenvolver gradualmente, incluindo futuras implementações de banco de dados e persistência de informações.

## 🎯 Objetivo

O principal objetivo do Café e Prosa é desenvolver um site de uso interno para o estabelecimento, que funcione como uma ferramenta de apoio ao atendimento e auxilie os clientes durante sua experiência na cafeteria, facilitando o acesso às informações, a consulta ao cardápio e a realização de reservas.

## 🛠️ Tecnologias

### Atualmente

* **Figma AI**  — criação e prototipação da interface visual.
* **HTML5** — estrutura e semântica das páginas.
* **CSS3** — estilização, identidade visual, layouts e responsividade.
* **JavaScript** — implementação de interatividade e funcionalidades dinâmicas do site.
